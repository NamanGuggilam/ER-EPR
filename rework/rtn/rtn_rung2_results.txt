  READ THIS BEFORE CALLING IT A SUCCESS:
  Non-adjacent single-site mutual information is identically zero at
  this order, so the boundary matrix is finite ONLY on the
  nearest-neighbour band and carries no information about longer
  separations.  H0 of a Vietoris-Rips filtration depends only on the
  minimum spanning tree, and both sides' trees are uniform paths, so
  an H0 match tests exactly one number per side -- the neighbour
  spacing -- and is blind to the bulk distances 2,3,4,5 entirely.
  H1 is empty on both sides, so W_H1 = 0 carries no information
  either (the same trap rung 4 documented).
